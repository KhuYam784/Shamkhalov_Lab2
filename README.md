# Демонстрационный проект для лабораторной работы № 2

Репозиторий используется для отработки основных операций Git на примере описания студенческого портала. Файлы содержат учебные текстовые данные, а не готовое приложение.

## Состав репозитория

- `main.txt` — согласованное описание личного кабинета и расписания после слияния веток.
- `helper.txt` — вспомогательные сведения об источнике демонстрационных данных.
- `feature1.txt` — описание функции переключения учебной недели.
- `interface.txt` — поля интерфейса расписания.

В истории показаны начальный коммит, параллельные изменения в `master` и `branch1`, разрешение конфликта при слиянии и откат коммита в `branch1`. Эта ветка добавляет описание проекта через Pull Request.
